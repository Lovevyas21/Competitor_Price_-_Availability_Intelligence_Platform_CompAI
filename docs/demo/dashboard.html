What broke

Three defects worth more than the features

Each was found by checking output against expectations, not by a test failing.

Forecast evaluation 0.15%→3.16%

MAPE looked excellent because it was scoring my own forward-fill. Irregular prices are resampled onto a daily grid so models see a regular frequency — and on a near-constant series, “predict the last value” is trivially right. Scoring now ignores filled days. Every model got worse, which is the point.

CDC throughput 3.3 h→41 s

The row-by-row path issued ~5 statements per record — fine on localhost, pathological at 298 ms round-trip. Rewritten set-based, so cost scales with batch, not record count. Both paths kept, with a parity test asserting identical output over late-arriving data, heartbeats and duplicates.

LLM guardrail 130 + 9→1309

The brief may only state numbers present in a validated facts payload. Run against my own deterministic output it flagged six — exposing a regex that matched at most three digits without a comma, splitting 1309 apart. A guard that cries wolf is a guard someone switches off.

Stated limitations

real, and not worked around

  • emptyOut-of-stock mart returns zero rows. Neither keyless source publishes availability. Built against the real schema so it works the moment a stock-bearing source connects.
  • thinOnly 4 of 22 series are fresh enough to forecast, each scored on a handful of points — too thin to trust per-series MAPE. The pipeline is correct; the source is sparse.
  • staleEvery undercut rests on old evidence. Recorded, labelled, and deliberately not delivered.
  • unappliedTerraform has never been applied. fmt and validate pass; plan has not run. Only syntax and provider schema are confirmed.
  • untestedThe CrewAI path has not run against a live model. No key configured; the guard and fallback are tested independently.
Every figure on this page was read from the running system on 1 September 2026, with the stack idle and marts freshly built. Nothing is estimated.
